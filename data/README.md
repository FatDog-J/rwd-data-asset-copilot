# Data Provenance

This project includes a small frozen corpus of selected publicly available
MIMIC website documentation files to make the RWD Data Asset & Methodology
Copilot demo reproducible from a fresh clone.

Upstream repository: `MIT-LCP/mimic.mit.edu`

Upstream URL: https://github.com/MIT-LCP/mimic.mit.edu

Upstream commit: `81822278432bc33e101116427e05fa4f69265a01`

Selected documentation files are stored in:

- `data/raw/mimic_docs/`
- `data/support/mimic_includes/`

These are documentation files only. They are not MIMIC patient-level clinical
data. The restricted MIMIC datasets have separate access requirements.

The selected files are included only to make this RAG demo reproducible.
